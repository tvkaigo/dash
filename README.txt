طريقة التشغيل:
1. فك ضغط المجلد كاملًا.
2. افتح index.html في Chrome أو Edge أو Firefox.
تعمل النسخة الموجودة في جذر المجلد دون خادم أو إنترنت، مع إبقاء الملفات منفصلة للتعديل.

بنية المشروع:
index.html: واجهة اللوحة.
style.css: التنسيق.
app.js: الحسابات والعرض والفلاتر الأساسية.
data.js: بيانات البلاغات وقوائم المدارس التي تحملها النسخة المحلية.
data.json: نسخة مقروءة من بيانات البلاغات.
school-lists.json: قوائم المدارس.
بقية ملفات JavaScript: فلاتر الأعمدة، قوائم المدارس، حقول التاريخ وتصدير إكسل.
jszip.min.js وJSZIP-LICENSE.txt: مكتبة إنشاء ملفات التصدير وترخيصها.
original-source: كامل ملفات المشروع الأصلي وإعداد نشره، كما تم استخراجها.

البيانات ثابتة داخل الملفات، ولا يوجد اتصال بقاعدة بيانات خارجية أو خادم خلفي.
المشروع الأصلي يحمل data.json.gz وschool-lists.json عبر fetch، ولذلك يحتاج خادمًا عند تشغيله محليًا.
عدلت النسخة في جذر المجلد لتحميل البيانات من data.js، لتعمل عند فتح index.html مباشرة.
لتعديل البيانات في النسخة المحلية يجب تحديث data.js؛ تعديل data.json وحده لا يغير البيانات المعروضة.
إعداد النشر الأصلي يشير إلى المشروع الحالي؛ أنشئ إعدادًا جديدًا إذا أردت نشر نسخة مستقلة.
